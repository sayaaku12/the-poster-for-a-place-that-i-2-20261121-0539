A program that draws the travel poster of Solmara — a place that isn't there — to /output/entry.png: a golden dusk over a turquoise lagoon, two moons in an indigo sky, a red-banded lighthouse on a rock islet beneath a natural stone arch, and the name SOLMARA set large in gold-shadowed serif.

## Run it

```sh
python3 main.py --self-test
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
